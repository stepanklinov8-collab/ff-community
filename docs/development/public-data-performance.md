# Загрузка публичных данных

Обновление от 20 октября 2026 года ускоряет чтение данных без изменения формул рейтинга, стоимости, состава справочника и параметров изображений. Миграция базы не требуется.

- Профиль передаёт уже полученную статистику вложенному блоку: первое открытие не создаёт второй одинаковый запрос.
- Независимые запросы сводной статистики выполняются параллельно. Общие итоги кешируются отдельно от страниц истории и выбранного режима.
- Рейтинги и сводка главной используют серверный кеш Next с интервалом перепроверки 30 секунд. HTTP-ответы статистики и рейтингов остаются `no-store`.
- Публикация и исправление результатов, модерация, настройки рейтингов, сохранение мероприятия и профиля сбрасывают соответствующие публичные данные через `invalidatePublicData`. Плановая обработка мероприятий тоже сбрасывает кеш. Новый серверный обработчик записи, влияющий на эти данные, должен вызывать сброс после успешной записи.
- Записи из старых клиентских обработчиков и изменения вне сайта становятся видны после автоматической перепроверки. Интервал 30 секунд не является строгой верхней границей задержки: Next может отдать прежнее значение во время фонового обновления. После явного сброса следующий запрос получает свежие данные.
- Главная получает гостевые счётчики и ближайшие сессии на сервере четырьмя параллельными запросами вместо шести запросов браузера в две очереди. При ошибке отображает сообщение с повторной загрузкой, а не ложные нули.
- Поиск команд ждёт 300 мс после ввода и отменяет предыдущий незавершённый запрос.
- Каталоги базы знаний загружаются отдельно для выбранного раздела; карты вынесены в отдельный компонент.

Кеш содержит только публичные проекции. Контактные ссылки, доступ к комнатам, личные кошельки, регистрация и проверки прав в него не входят. Главная использует анонимный ключ и гостевые RLS-политики, без сессии посетителя. Приватные ответы профиля сохраняют прежние правила доступа.

Проверки в `tests/browser/performance.spec.ts` используют локальную замену транспорта Auth/PostgREST: проверяют неизменность значений и исключение неполных сессий, отсутствие повторных запросов, параллельное чтение, обновление после записи, отказ неавторизованному пользователю, серверные счётчики, поиск и отдельную загрузку каталога. Проверка профиля дополнительно контролирует один запрос статистики при открытии.

Перед выпуском проведено сравнение всех девяти каталогов с предыдущей версией: 211 записей совпадают полностью, включая тексты, характеристики и ссылки на изображения. Код отображения карт и параметры изображений главной также совпадают. Файлы изображений, размеры, качество, обработка загрузок и настройки Next Image не изменены.
