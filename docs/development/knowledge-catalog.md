# Knowledge catalog corrections — 2026-10-06

Sources: [official maps](https://ff.garena.com/en/maps/), [weapons](https://ff.garena.com/en/weapons/), [characters](https://ff.garena.com/en/chars/). Public catalog snapshot collected on 2026-10-05.

- Maps now contain 109 verified labels: Solara 14, Nexterra 13, Alpine 16, Bermuda Remastered 18, Bermuda 21, Purgatory 14, Kalahari 13. Solara retains the approved atlas coordinates, font and 17-unit anchor offset unchanged. Other maps use horizontal label centres registered to the official background by matching terrain features. Cyrillic labels scale with the map. Nexterra's source image has baked English text; HTML label backgrounds cover those names in place.
- Existing landing-location IDs remain stable for saved results. The result-entry location catalog remains broader than the featured clickable points in the official atlas. Additional points must have verified coordinates before they are displayed on the map; never generate positions by list order.
- The official weapon list contains 80 entries (the initial page response contains only 12). All 80 are included locally with images, 11 category filters, individual Russian descriptions, eight statistic fields and the attachments flagged in the source. Source zero placeholders become null and render as a dash, not a measured zero. Magazine is a capacity; other attributes are catalog scale values, not guaranteed HP damage, metres or seconds. Do not invent reload times, projectile intervals or body-part damage tables. The Thompson source abstract mistakenly describes a shotgun; its description instead uses its verified submachine-gun category. MP40 attachment prose conflicts with structured flags; the page labels these as attachments marked in the catalog rather than claiming exclusive compatibility.
- All 65 official character profiles now include full-body artwork, an original Russian biography summary, age/birthday/gender, ability description and every numerical parameter supplied by that character's English detail page, checked 2026-10-06. Morse, Ryden, Luna, Koda and Jai supplement the prior 60. Unknown Wukong age (source 0) is null. Six awakened abilities are explicitly separated from qualitative base abilities; do not silently substitute awakening for the base skill or mix older numerical balance values into current cards. Source URLs and verification dates are retained per record. Images remain lazy-loaded from the official CDN; navigation and text stay on this site.
- The official detail pages omit numerical values for many older characters. Missing timings, damage and percentages are explicitly identified as unpublished, not inferred. Kelly's 106% first-shot damage means a 6% bonus, not +106%. Character ages are fictional biography values, not real-person ages.
- No database migration or external write is required. To update the snapshot, verify public sources and commit catalog changes; the site does not crawl the source during normal page requests.
