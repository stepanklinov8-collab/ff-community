# Выход из команды или гильдии: проверка 26.10.2026

Обычный участник и заместители могут выйти из активной организации. Лидер сначала передаёт лидерство. Выход удаляет только собственное текущее членство; другое членство и опубликованная статистика сохраняются.

## Что проверено в production без изменения данных

- `leave_organization(uuid)` присутствует, `authenticated` имеет право вызова, `anon` — нет.
- Действующие триггеры соответствуют миграциям: проверка состава при добавлении/изменении и пересчёт рейтинга при изменении членства.
- Пустых ролей, расхождений роли лидера с `teams.leader_id`, внешних ключей на строку членства и ожидающих блокировок состава на момент проверки не найдено.
- В запрошенном окне 23 часа журнал API содержал только ответы 200/204 для пути выхода. Это не доказывает отсутствие проблем до этого окна или в браузере, который вообще не отправил запрос.
- Пользователь сообщил, что обычный участник видит кнопку, но не выходит; текст ошибки и поведение подтверждения неизвестны. Конкретную причину того случая установить нельзя.

## Устранённые слабые места интерфейса

1. Подавление браузером `window.confirm` раньше молча отменяло действие. Подтверждение теперь находится внутри страницы, рядом с кнопкой; отмена не отправляет запрос.
2. Ошибки раньше появлялись в общем сообщении вверху страницы. Теперь ошибка и «Проверить состав» находятся внутри блока выхода.
3. Запрос и проверка авторизации имеют конечное ожидание; `finally` освобождает кнопку. Синхронный замок защищает от повторных нажатий.
4. При ошибке ответа проверяются авторизованный аккаунт и текущее членство. Если выход уже выполнен, интерфейс обновляется без второй мутации. Сбой проверки не считается успешным выходом.
5. Перед отправкой сверяется текущий аккаунт. После выхода очищаются состав, права управления и предложение лидерства на странице; переход в каталог заменяет текущую запись истории браузера.

Функция базы и её правила в этом исправлении не меняются. Проверки выхода выполняются на локальных данных; реальных участников в production тесты не выводят.

## Покрытие

- `tests/browser/leave-organization.spec.ts`: обычный участник команды/гильдии, заместители, лидер, гость, посторонний, распущенная организация, отмена, запрет сервера, смена роли, отсутствующая RPC, смена/истечение входа, потерянный успешный ответ, уже удалённый участник, сетевая ошибка, ошибка повторной проверки, тайм-аут и повторные нажатия.
- `tools/database-tests/leave-organization.mjs`: вызов под реальной ролью `authenticated`, запрет гостю/лидеру/постороннему, все не-лидерские роли, повторный вызов, сохранность второго членства и количества опубликованных фактов/истории/регистраций.
- Браузерные API подменяются тестовым транспортом; SQL исполняется в PGlite с актуальными миграциями. Это не проверка всех физических устройств и встроенных браузеров мессенджеров.

Имена игрока в старых результатах и ранее зафиксированных составах могут оставаться после выхода: история участия не равна текущему членству в организации.
