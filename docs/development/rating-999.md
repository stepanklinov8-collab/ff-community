# Основные спортивные рейтинги

## Личный рейтинг

У игрока рейтинг появляется после десяти сыгранных игр в опубликованных сессиях с полной личной статистикой. Если в любой сыгранной строке сессии нет личных киллов или их сумма не совпадает с киллами команды, всю сессию исключаем из личного расчёта. Незавершённые и несыгранные игры не учитываем.

Для каждой допустимой игры: `x = личные киллы / киллы команды`; при `0/0` вместо `x` берём `1/4`. `K = личные киллы / все киллы игры + x`; доля от всех киллов равна нулю, если их никто не сделал. `P = n + 1` для первого места, иначе `n + 1 − место`, где `n` — число действительно сыгравших команд. `D` — разность фактического и прогнозного нормированных мест команды на этой карте, в пределах `−1…1`; для старых игр без сохранённого прогноза `D = 0`. Тогда `A = K + x × P × (1 + D)`.

Игры группируем по текущему коэффициенту мероприятия, вычисляем среднее `A` внутри каждой группы, затем `среднее_с_весом = Σ(коэффициент × среднее_A_группы) / число_групп`. Общий `У/С = сумма личных киллов / число допустимых игр`. Сырой рейтинг равен `У/С × среднее_с_весом`. Бонусы за места и MVP вместе ограничены 499; итог ограничен 999. Изменение коэффициента мероприятия пересчитывает всю опубликованную историю.

## Прогноз места

Перед стартом сессии сохраняем для каждой зарегистрированной команды и карты распределение вероятностей мест. Источник — уже опубликованные игры этой команды на этой карте. Историческое место переводим в долю поля и обратно в место при нынешнем числе зарегистрированных соперников; игры с более близким размером поля имеют больший вес. Самое вероятное место становится прогнозным. При равной вероятности выбираем ближайшее к среднему прогнозному месту. Без истории на карте прогноз не создаём и используем `D = 0`. После старта сессии сохранённый прогноз не переписываем.

## Рейтинг команды или гильдии

Основной рейтинг появляется после первой сыгранной сессии. `55%` оценки составляет среднее точных рейтингов четырёх сильнейших действующих игроков; у ещё не ранжированных игроков вклада нет. `35%` составляет результат сессий. Для каждой сессии `факт = (n − место)/(n − 1)`, `D = факт − среднее сохранённых прогнозов карт`, `Q = факт × (1 + D)/2`. При отсутствии прогноза отдельной карты вместо него используем факт, поэтому такая карта не меняет `D`. Среднее `Q` по сессиям взвешиваем текущими коэффициентами мероприятий. По `5%` дают достижения и репутация, нормированные из существующей шкалы `1…100`. Бонус серии — до пяти очков. Итог: `clamp(1, 999, 0,55 × лучшие_игроки + 0,35 × 999 × среднее_Q + 0,05 × 999 × достижения/100 + 0,05 × 999 × репутация/100 + бонус_серии)`.

Место команды за сессию учитываем один раз независимо от числа игр. Команды без сыгранных сессий остаются без основного рейтинга. BO и КВ сохраняют независимые рейтинги. Старая формула стоимости остаётся по структуре прежней, но её входной спортивный рейтинг нормируется на `999`, а не обрезается на `100`. В модели коэффициентов ставок основной рейтинг тоже переводится к прежней внутренней шкале, чтобы значения выше ста сохраняли различие.
