# Значок OMCITE на главном экране

Страница `/install` предназначена для ссылки в VK, Telegram и других чатах. Она доступна без входа и есть в общем боковом меню. Установка использует возможности браузера; APK, аккаунты магазинов и платежи не нужны.

- Android / Chromium: кнопка появляется после `beforeinstallprompt`. Одноразовый запрос хранится в корневом провайдере и сохраняется при переходах внутри сайта. Отмена и сбой показывают инструкцию; принятие запроса не подменяет событие `appinstalled`.
- iPhone / iPad: Safari → «Поделиться» → «На экран Домой». При наличии переключателя открытия как веб-приложения его нужно включить.
- Встроенный браузер мессенджера: открыть ссылку во внешнем браузере; при отсутствии такого пункта скопировать её вручную.
- Страница предлагает системное меню обмена ссылкой, если оно поддерживается, и копирование с ручным запасным вариантом. Получателей выбирает пользователь. Ссылка формируется из текущего origin.

`src/app/manifest.ts` задаёт постоянные `id`, `scope` и `start_url` `/`. Значок открывает главную страницу существующего сайта в режиме `standalone`, если браузер его поддерживает. Данные и авторизация остаются в существующей системе. Интернет необходим; автономная работа не обещается. В зависимости от браузера создаётся веб-приложение или ярлык.

Из `public/brand/omcite-emblem.jpg` подготовлены PNG 192×192, 512×512, Apple touch 180×180 и отдельный maskable 512×512. Для maskable исходник уменьшен до 360×360 и помещён по центру чёрного фона 512×512. Новые иконки лежат в `public/icons`. Для воспроизведения можно использовать Sharp из текущего окружения Next.js: resize → png; для maskable — composite по центру. Root metadata подключает манифест, Apple icon и цвет интерфейса.

Существующий Firebase service worker не заменяется. Новый worker и кэширование личных страниц/API не добавляются. Миграций базы и изменений переменных окружения нет.

Проверки: `tests/browser/install.spec.ts` проверяет манифест браузером, размеры и загрузку PNG, перенос запроса установки между страницами, отмену/подтверждение, самостоятельный режим iOS, ручное копирование, мобильную ширину 320 px и переводы. Браузерные тесты моделируют системные события; фактическая установка на физическом Android/iPhone требует проверки на устройстве.

Справка платформ: [MDN — installable PWA](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable), [Apple — website on Home Screen](https://support.apple.com/en-lamr/guide/iphone/iphea86e5236/ios).

Откат: откатить коммит с этой функцией и выпустить предыдущую версию сайта. Уже добавленные значки по-прежнему ведут на `/` того же домена; данных пользователей функция не меняет.
