# Рейтинг организаций, стоимость, OMCITE Coins и резерв

Согласованный выпуск без отложенного обновления дизайна.

- База организации: сумма четырёх лучших точных рейтингов текущих участников / 4. Недостающие рейтинги — нули.
- Выступления включаются после 10 допустимых игр организации. Для каждого веса мероприятия используется квадрат среднего квадратного корня оценки места относительно сохранённого прогноза. До накопления десяти игр база, достижения и призовые уже учитываются.
- Общая дополнительная часть: не более 499; общий рейтинг организации: не более 999, отображение целым числом. У пустой организации без достижений рейтинг и цена равны нулю.
- Стоимость игрока: S-кривая полезности до 500 очков (93 737 550) + согласованная кривая дополнительных очков до 499 (6 262 450) + `4000*(sqrt(1+взвешенныеПризовые/10000)-1)`. Выше 500 цена полезности не растёт.
- Стоимость организации: точные цены **всех** текущих участников + `(1+рейтинг/суммаРейтингов)` × цена собственного рейтинга + прибавка за призовые. Основная часть рейтинга стоит до 700 млн, дополнительная до 300 млн. Полная цена может быть выше миллиарда.
- Дробные дополнительные очки оцениваются линейно между соседними уровнями. Округляется только итоговая цена, до целого.
- OMCITE Coins — единица стоимости, кошелька, ставок, взносов и призовых. Масштаб чисел 1:1. Балансы и история проводок не переписываются.

## Подтверждённые призовые

Администратор указывает приз команды в редакторе результатов и публикует исправление. Эта сумма участвует в оценке; запись **не переводит деньги между кошельками**.

Для личной доли используется сумма киллов игрока / сумма киллов всех игравших в составе, включая гостей, затем вес мероприятия (тренировка 1, турнир 1,2). При нулевых киллах всего состава приз делится поровну между фактически игравшими. При неполных личных данных вся личная раскладка сессии ждёт заполнения. Доли гостей не присваиваются зарегистрированным игрокам. При копировании гостя на следующую карту сохраняется его идентификатор. Исторические разные гостевые идентификаторы автоматически не объединяются.

Призовые многоэтапных турниров отложены. Старые неизвестные суммы не выдумываются. Коррекция заменяет прежнюю награду, отменённая сессия перестаёт учитываться. Общие победы и киллы не увеличиваются от ввода призовых.

## Резерв

После заполнения основного лимита запись продолжается в резерв. Номер показывается по времени записи и ID при равенстве времени, в том числе собственным участникам при закрытом общем списке. Основной счётчик показывает только подтверждённые заявки.

До закрытия регистрации освободившееся место автоматически получает первая допустимая заявка. Проверяются ограничения, верификация организации и актуальность состава. После закрытия организатор/администратор переводит заявку вручную до блокировки состава. Ответственный за сессию и обычный участник не могут использовать этот перевод или обходить его через редактирование.

## Проверки и восстановление

Две миграции применяются атомарно. Проверены доменные правила, сценарии БД, сохранение призовых и приватный резерв в Chromium, production-сборка, TypeScript, lint и границы модулей. Репетиция пересчёта на локально восстановленных данных сайта сохраняет все существующие личные рейтинги, факты игр и балансы.

Полный `pg_dump` из текущей сети недоступен: IPv6 не маршрутизируется, pooler разрывает соединение. Через официальный Management API сохранён согласованный локальный снимок данных 128 таблиц public/Auth/Storage/истории миграций, определений функций, триггеров, ограничений и политик. Это **не полный pg_dump**: не гарантирует восстановление всего проекта с нуля, не содержит файлов из Storage. Снимок и адресный SQL отката хранятся в исключённой из Git папке `tools/database-tests/artifacts/economy-release`.

Применение и полный транзакционный откат проверены на тестовом Supabase. Адресный откат возвращает изменённые функции, триггеры и прежний расчёт по текущим фактам, сохраняя результаты, регистрации и кошельки. Дизайн в отдельной локальной рабочей копии в выпуск не включён.
