# Проверка готовности к деплою обновления №2

25 сентября 2026 года. Итог: **обновление №2 развернуто**. Коммит `e3282184052538fcca1f9f10469fecf48e9e05e6` опубликован в `main`, Vercel сообщил успешный production-деплой.

## Подтверждено

- Локальные результаты предыдущей проверки сохраняют силу: успешная сборка, 23 теста модели и импорта, 16 групп SQL-проверок, 26 миграций в PGlite, чистый ESLint и аудит зависимостей.
- Главная ветка удалённого репозитория содержит коммит `e3282184052538fcca1f9f10469fecf48e9e05e6`.
- Создан бесплатный staging-проект `ff-update-2-staging`; 26 миграций и пересчёт на нём прошли успешно. В рабочем проекте также применены все 26 миграций и выполнен пересчёт.
- Полный SQL/Auth дамп рабочей базы не создан: `pg_dump` через Supavisor закрывает соединение при чтении системных каталогов. Это ограничение зафиксировано; 70 файлов Storage (42 349 205 байт) сохранены в локальном исключённом из Git архиве.
- Выполнен только запрос чтения системных метаданных через специальный endpoint `database/query/read-only`. В базе нет `cron.job` и расширений `pg_cron`/`pg_net`. Приватный bucket `competition-evidence` уже существует, но его наличие не подтверждает права и операции нового приложения.
- В репозитории есть GitHub Actions с периодичностью пять минут; фактическая доставка push после выпуска отдельно не выполнялась.

## Ограничения после выпуска

1. Полный SQL/Auth дамп рабочей базы не получен из-за сбоя `pg_dump` через Supavisor; перед следующими изменениями нужен рабочий способ резервирования.
2. Полный пользовательский сквозной сценарий с отдельными аккаунтами, реальный OCR и фактическая push-доставка в этой сессии не выполнялись.
3. Планировщик остаётся GitHub Actions раз в пять минут; для минутного интервала требуется отдельный внешний планировщик.

После закрытия этих условий разрешение владельца на деплой уже имеется; повторное общее согласие не требуется. Новые расходы или изменения вне согласованного объёма нужно обсуждать отдельно.

Источники проверки: локальные `acceptance.md`, `migration-report.md`, `release.md`; результаты Management API и read-only SQL в игнорируемой папке `tools/database-tests/artifacts/deployment-*-preflight*.json`, `deployment-preflight.json`. Секреты в отчёт не включены.

Справка Supabase: [резервные копии базы не содержат сами файлы Storage](https://supabase.com/docs/guides/platform/backups); [специальный API запросов только для чтения](https://supabase.com/docs/reference/api/v1-read-only-query).
