## Что подготовлено

- Общий редактор мероприятий пяти режимов, сессий, групп, игр и квалификации; общий набор полей создания/изменения. Расчёт недостающих групп по вместимости, поиск и подгрузка списков.
- Проверка организаторов, золотой статус, отдельное одобрение существенных изменений с сохранением действующей версии до решения.
- Снимки составов/имён, постоянные ID, десятиминутная блокировка самостоятельного изменения, распределение и перенос квалификации, сохранение уже начавшегося этапа.
- Единые черновик и публикация целой сессии; личные, командные и гостевые результаты, импорт XLSX/CSV/JSON, OCR с ручной проверкой, приватные доказательства и ZIP.
- По просьбе пользователя 24.09 добавлена кнопка «Заменить гостем»: сохраняет заявленного игрока как несыгравшего, добавляет гостя с пустыми полями только в выбранную игру. Все зарегистрированные игроки имеют отдельные показатели; для БО/КВ также смерти и помощи.
- Атомарные исправления статистики, рейтингов, предупреждений и виртуальных выплат; повтор запроса безопасен, конфликт версии выявляется. Полная отмена события возвращает ставки, включая ранее выплаченные.
- Независимые main/solo/БО/КВ, полная точность рейтинга, хронологический пересчёт серий, MVP, два согласия текущей версии отдельного КВ и отдельное решение администратора.
- Предупреждения, репутация, 30-дневные отстранения, запреты участия, чёрные списки, приватные однократные обжалования, заморозка/передача/отмена мероприятия.
- Публичные итоги/история/рейтинги, архив по времени, окна комментариев, адресная очередь уведомлений. Новые ключевые формы RU/KK/KY.
- 26 миграций, сохранение старой неполной истории с приватным реестром неопределённых данных; единый SQL полного перерасчёта.
- Совместимые исправления зависимостей, Next.js/eslint-config-next 16.3.6, uuid 11.1.1 для ExcelJS. npm audit: 0.
