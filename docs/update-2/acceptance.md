## Браузерные сценарии

Проверка собранного приложения с искусственными ответами API и отдельная проверка настоящих SQL-функций в PGlite. Искусственная публикация в браузере не обращалась к рабочей базе.

1. Пустые убийства блокируют публикацию, явный ноль разрешён.
2. Автосохранение больше не закрывает предварительную таблицу. Подтверждение переводит форму в состояние «Опубликовано».
3. Поиск находит последнюю из 1024 заявок. Редактор результатов также проверяет всю сессию, включая последнюю запись, независимо от видимой страницы.
4. Ключевые поля и действия результатов отображаются на RU/KK/KY. На экране 390 × 844 страница не расширяется по горизонтали; проверены результаты, заявки, создание КВ и редактор мероприятия.
5. При выборе двух побед в серии КВ форма добавляет три игры. Все пять карт доступны.
6. Для лимита сессии 36 и вместимости 12 редактор добавляет недостающие группы, получаются три группы. Существующие группы и их ID сохраняются.
7. У каждого из четырёх игроков есть отдельное поле убийств. Кнопка «Заменить гостем» оставляет исходного игрока с отметкой «Не играл», добавляет гостя с пустыми показателями и действует только в выбранной игре.
8. После заполнения 5/2/1 и 6 у гостя, публикации и повторного открытия значения сохранены; следующая игра сохраняет исходный состав. На уровне модели второе место даёт 23 очка за эту игру; в двухигровой браузерной сессии сумма — 32 (23 + 9).
